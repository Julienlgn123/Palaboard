# 🌟 Projet **PalaBoard**

## 📚 Présentation

**PalaBoard** est une plateforme dédiée au référencement de serveurs **Discord** liés à l’univers **Paladium**.  
Elle permet aux joueurs de découvrir facilement :

- des **serveurs de factions**
- des **serveurs market/shop**
- des **communautés spécialisées** autour de Paladium

---

## 🎨 Identité visuelle

- **Nom** : *PalaBoard*  
- **Logo** : *(celui partagé précédemment, au style moderne et gaming)*  
- **Thème** : Couleurs **néon** (vert, bleu, violet) sur **fond sombre**, dans un esprit **gaming/tech**

---

## 📜 Fonctionnalités principales

### 🛠️ Ajout d’un serveur

Un formulaire fluide et animé pour référencer un serveur :

- 📛 **Nom du serveur**  
- 📝 **Description**  
- 🆔 **ID Discord** *(utilisé pour automatiser certaines vérifications)*  
- 🔗 **Lien d’invitation Discord** (permanent, sans expiration)  
- 🖼️ **Logo du serveur** *(upload ou glisser-déposer)*  
- 🖼️ **Bannière du serveur** *(upload ou glisser-déposer)*  
- 🗂️ **Catégories** *(sélection multiple parmi celles-ci)* :

```text
🧱 Miner · 🌾 Farmer · 🏹 Hunter · ⚗️ Alchimiste  
🏰 Base-Claim · 💣 Pillage · 🎁 Giveaway  
🎯 Concours · 🎯 Drop2Bc · 🛡️ Faction
```

---

### 🔥 Bump système

- Bouton de **bump** pour remonter temporairement un serveur dans la liste
- **Captcha simple** à chaque bump *(images, puzzles, textes déformés)* pour éviter le spam
- **Cooldown configurable** *(ex. : 2h entre chaque bump par serveur)*

---

## 🧩 Fonctionnalités secondaires

- 🔍 **Barre de recherche rapide** *(par nom ou catégorie)*
- 🥇 **Mise en avant** des serveurs les plus bumpés
- ✨ **Badges spéciaux** :
  - *Nouveau*
  - *Top*
  - *Vérifié*
- 📈 **Statistiques** :
  - Nombre de vues
  - Nombre de clics sur le lien
- 🚀 **Classements** :
  - *Top bump*
  - *Top nouveaux*
  - *Top actifs*
